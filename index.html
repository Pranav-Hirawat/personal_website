  1. 01

    Intelligent API Security Gateway

    Python Redis Go 2026

    Four-person project — I built and own the Python control plane.

    Problem
    A gateway can block a bad IP, but attackers rotate addresses. Judging each request in isolation means the same actor is re-detected forever and never actually stopped — six IPs grinding one login form read as six unrelated incidents instead of one credential-stuffing campaign.
    Built
    The agentic half of the system: a control plane that wakes every 30 seconds to correlate, decide and write policy, while a Go proxy does the enforcing. Clustering over shared traits — endpoint, User-Agent, subnet, overlapping timing — groups scattered evidence into campaigns that survive an attacker changing every address. Severity and confidence then map onto an action ladder (monitor → throttle → temp block → escalate), written to Redis with a TTL so every decision expires on its own rather than needing to be revoked.
    Design
    The LLM narrates incidents but runs strictly after enforcement, so a prompt-injected summary can mislead a reader and still never unblock an attacker. It's optional too — a null provider means the system runs with no model at all. The rails that matter (never action reserved ranges, never write a policy without an expiry, cap IPs per cycle, honour dry-run) live together in the one file that can influence the gateway.
    Outcome
    3,925 lines of source against 3,289 lines of tests: 249 tests at a 0.84:1 ratio, testing properties rather than paths — including that clean traffic produces zero detections. One runtime dependency; the rest is standard library. Kill the control plane and the gateway keeps serving traffic unchanged — it just stops getting smarter.
  2. 02

    Fake Review Detector

    Python NLP scikit-learn Streamlit 2026

    Problem
    Computer-generated product reviews read as fluent and confident as real ones, which is exactly what makes them hard to spot by eye and easy to buy in bulk.
    Built
    A text classifier over a cleaned, stopword-stripped, TF-IDF corpus, comparing logistic regression against naive Bayes, then wrapped in a Streamlit app that scores a pasted review in real time.
    Outcome
    ~89% accuracy, read through a confusion matrix and precision/recall/F1 rather than accuracy alone — on a task where a false accusation costs more than a miss.
