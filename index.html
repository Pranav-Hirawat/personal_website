01 — Selected work

Intelligent API Security Gateway

Four-person project — I built and own the Python control plane.

PythonRedisGoOllama2026

Problem. A gateway can block a bad IP, but attackers rotate addresses — six IPs grinding one login form read as six incidents instead of one campaign.

Built. A control plane that wakes every 30 seconds to correlate evidence into campaigns, then maps severity and confidence onto an action ladder written to Redis with a TTL, so decisions expire on their own.

The decision I'd defend. The LLM narrates incidents but runs strictly after enforcement — a prompt-injected summary can mislead a reader and still never unblock an attacker. One test feeds the pipeline ordinary traffic and fails if it reports a single detection.

02 — Selected work

RAG Chatbot with Web Search

PythonLangChainChromaOllamaDuckDuckGo

Problem. A model that only knows its training data can't tell you anything current; one that only searches the web knows nothing about your documents. Most answers need both.

Built. Documents chunked, embedded and stored in Chroma for semantic search, queried in parallel with a live DuckDuckGo search, then handed to a local Gemma model through Ollama to synthesise one answer. Inference runs on the machine — no API keys, nothing leaves the box.

What I'd fix first. It answers every question from scratch, with no memory of the last one. That keeps retrieval honest — nothing leaks in from earlier turns — but it rules out follow-ups, and conversation state is the next thing I'd build.

03 — Selected work

Fake Review Detector

PythonNLPscikit-learnStreamlit2026

Problem. Computer-generated reviews read as fluently as real ones, which is what makes them hard to spot by eye and easy to buy in bulk.

Built. A supervised pipeline over a cleaned, stopword-stripped, TF-IDF corpus — several algorithms compared and their hyperparameters tuned before picking one — deployed as a Streamlit app that scores a pasted review live.

The decision I'd defend. Judged on a confusion matrix and precision/recall/F1 rather than accuracy, because on this task a false accusation costs a seller far more than a missed fake costs a shopper.

    06 — About

    I'm drawn to the part of a system that has to decide something under uncertainty — where the interesting question isn't whether the code runs but whether the call it made was the right one, and what happens when it wasn't.

    That's most of what the gateway project became. Blocking a bad IP is easy; recognising that six addresses are one attacker, choosing an action proportionate to how sure you are, and making sure a language model can narrate the incident without ever being able to influence it — that's the actual work. The same thread runs through the smaller projects: a chatbot that has to say where an answer came from, a classifier where a false accusation costs more than a miss, and an iOS app that has to stay useful when the network doesn't.
